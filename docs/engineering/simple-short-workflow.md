# 短片默认流程简化

新建15～60秒短片默认由动态提示词和内置技能路由到现有video_project直接制作，不创建film_project。只合并澄清缺失需求，video_script使用插件文本模型准备完整脚本与分镜，内部自检后补齐估价及绑定示意图，再执行一次video_project review。生成工具保留费用确认，分段暂停保留review_segment；不增加开始制作确认。

普通短片不固定先问完善意愿或另选风格；按原意准备完整方案，风格推荐写入待审核材料。实质改变主题、情节、关系或结尾仍先征得同意。普通项目局部修改沿原项目改稿并重新review，不因修改一句对白转到专业项目。

超过60秒、用户明确要求专业分阶段或独立终审、已有film_project续作继续专业流程。原审批、分章、修订号、制作绑定及恢复记录均保留；不自动迁移、批准或绕过现有守卫。普通写作自检不冒充独立终审。该改动是模型编排入口规则，不宣称已将专业工作流引擎的全部阶段合并；旧专业项目仍会按其原阶段请求批准。

内部阶段不连续播报，仅在需要决定、较长等待、阻断或交付时说明进度。需求完整、已指定规格和风格时不增加选择。普通prepare成功的返回也指向video_script、storyboard与一次review，编译专业项目仍沿用原制作方案。
