# 本地诊断日志

位置为 `<DSH_HOME>/logs/metaontic-video/YYYYMMDD/requests.jsonl`，未设置 DSH_HOME 时使用系统用户目录下的 `.dsh`。日志文件权限600、目录700；Windows权限仍由系统ACL控制，不将POSIX权限位等同Windows访问隔离。

入口只接受固定字段，忽略正文、鉴权、任意对象与原始错误。字符串脱敏并限256字，路径只保留文件名；接缝裁切只保存有限的段号及秒数。时间、插件版本与日志协议版本由记录器生成，不允许调用方覆盖。

工具自动关联callId、sessionId、projectId、taskId和段号；嵌套阶段关联parentSpanId。无法从宿主取得的信息不伪造。助手标记跨调用结束时保留开始时上下文。错误使用固定分类，审批受阻、暂停、部分完成和提交结果不明不计为成功。正文不作为诊断依据写入文件。

日志写入队列上限256，单日5MB；超过时丢弃并计数，不中断制作。每小时清理一次30天前日志或超过50MB阈值的最旧日志，当前文件不删除，因此清理间隔内总量可能临时增加至约55MB。仅删除日期目录内的普通requests.jsonl，不跟随符号链接、不递归删除其他文件。

video_config(action:get)的logging返回本进程written/dropped/failures/cleanupFailures、最近失败分类及时间、最近成功时间和队列长度。故障不会写入相同日志递归报告，不会触发重新生成或重提付费请求。计数随进程重启归零，最近错误保留作历史诊断，不代表仍处于故障。

node --test在未明确指定DSH_HOME时关闭文件日志；落盘测试使用临时目录。测试不会清除用户已有历史记录。验证包含脱敏、写入失败恢复、容量上限、清理边界与并发上下文。Windows/macOS共享Node路径与文件API；此轮本机自动测试不代表Windows桌面实测。
