# 提示词流程优化核对

- 普通流程调用 video_script；专业阶段按 film_project 当前角色创作和 submit，独立终审仍通过 independent_review。不存在额外的专业脚本生成 API，不将角色执行冒称独立模型调用。
- 新增统一路由、状态与提问契约；沿用 nextTask，保护用户拒绝、原任务防重、付费审批和分段审核。
- 合并创意澄清和规格规则，详细写作方法按阶段加载；没有删除计费、安全或交付守卫。常驻状态表提升明确性，不宣称整体 token 已显著下降。
- 生成字段仍为 prompts[].prompt。专业校验要求对白原文出现在 prompt，发音映射不能绕过该校验，仅在实际制作审核阶段应用。
- 无音频与无对白分别处理，禁止把无对白误解成无环境声和配乐。
- 客服旁新增提交问题反馈，打开 Gitee 新建问题页，不自动上传日志、文件或凭据。

验证：构建、类型检查和777项自动测试通过；八个提示词场景检查实际注入契约，现有测试覆盖批准、恢复、防重、局部失效等程序行为。静态断言及模拟接口不等同真实模型遵循度测评；未进行付费视频调用、模型 A/B 对照或桌面点击验证。

Windows/macOS：新增反馈链接使用浏览器标准 HTTPS 导航，提示词无平台专属路径和进程变化；未做 Windows 桌面实测。本次未安装、未发版。
