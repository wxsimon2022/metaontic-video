# 插件统计实现与边界

插件在后台向服务端 `/api/v1/analytics/events` 发送白名单事件；控制台 `/admin/#/plugin-analytics` 通过登录后接口查看聚合与设备列表。服务端代码位于独立的 MetaOnticVideoService 仓库。

只有正式版 `X.Y.Z` 参与统计：测试版（如 `3.22.9-test.2`）与未注入版本号的开发构建直接返回空实现，不写匿名身份文件、不起定时器、不发任何请求，也不占用队列。

## 不影响创作

工具入口不等待网络、身份文件或上报结果；异常不改变工具结果与错误。队列最多 200 条，每批 20 条，默认延迟 1 秒发送，请求 1.5 秒超时，每条最多尝试 3 次。定时器不阻止退出，卸载取消请求并丢弃队列，不等待补发。安装监听只旁路观察宿主操作，读取安装来源最多等待 1 秒，监听、归类或排队失败都不会影响安装、加载与工具执行。设置页「高级设置 → 使用统计」可关闭；开发验证可设置 `METAONTIC_VIDEO_ANALYTICS_DISABLED=1`。

## 真实安装完成

`plugin_installed` 只认宿主 `plugin-manager/operation` 的真实安装结果：操作目标为本插件、阶段为 `enable`、已进入 `settled`、`changed=true`、没有错误，且 `application` 为 `applied` 或 `restart-required`；失败、取消与 `overridden` 都不计数。事件按宿主操作 ID 在本地幂等，时间与版本优先采用宿主操作记录；首次安装与成功更新都会记录。

安装来源只上报固定枚举 `npm`、`tgz`、`directory`、`git`、`bundled`、`unknown`，由宿主安装记录归类；完整 URL、路径、凭据与原始来源字符串不上报。读取来源超时、失败或宿主未返回匹配记录时回落 `unknown`。

安装完成不等同首次启用：若安装后插件未激活、需要重启才能加载，或安装时没有启用，插件来不及监听，就不会产生该事件；后续首次加载仍由 `plugin_started` 识别。服务不可用、关闭统计、离线或退出丢弃会令数据不完整，但不会阻塞任何插件操作。

## 字段与统计口径

仅接收插件启用、真实安装完成、工具开始/完成、视频任务创建/终态事件，以及固定枚举的工具、模式、安装来源、状态、错误类型和调用耗时。附系统类型、内核版本、CPU 架构、取整内存、Harness 与插件版本。不包含对话、创意、提示词、媒体、API 密钥、用户名、MAC 或序列号。安装标识是本地随机 UUID，服务端仅存其 SHA-256；任务 ID 仅参与本地散列，不上传原值。身份文件在宿主数据目录 `state/metaontic-video/` 下写两份（`analytics-id.json` 与冗余的 `analytics-anchor.json`），只在两份都不存在时才分配新标识；删掉其中任意一份（手删、清状态）都不算新设备，下次读取会用幸存的那份把另一份补回来，两份对不上时以 `analytics-id.json` 为准并自愈。首次初始化和修复均持跨进程独占锁，拿锁后重新读取主文件和锚点，以临时文件原子替换；只恢复确认已退出的本机进程锁。活跃锁有界等待约1秒，读写失败不永久缓存空身份，下次上报重新尝试。多进程实测覆盖12个进程同时首次初始化。仍然不是硬件指纹：整个 `state/metaontic-video/` 被清掉、或把整份宿主数据目录复制到另一台机器，会分别造成多算一台与两台算一台，这是有意保留的隐私取舍。首次成功接收代表首次启用，不是下载量或人数；安装完成来自宿主真实安装操作，包含首次安装与成功更新，未激活或来不及监听时仍只能按首次启用统计。关闭统计、旧插件、离线或丢弃事件都会使数据不完整。

服务端按安装标识与事件 ID 幂等入库，限制请求体和 IP 频率，统计接口要求控制台登录。原始事件默认保留 90 天，首次启用记录保留；请求日志仅记录事件数。按北京时间聚合，控制台展示安装完成次数、每日趋势与安装来源分布；视频任务数依据创建事件，终态重复查询不重复计数；调用耗时不是上游纯生成耗时。

## 平台与验证

Windows/macOS 共用 `node:os`、`node:path` 与随机标识实现，状态位于宿主数据目录，不硬编码开发机路径。插件统计测试 19 项覆盖正式版判定、白名单、掉线/超时/重试、队列上限、禁用、退出、热加载去重、工具失败隔离、真实安装完成与来源脱敏，以及匿名身份的并发/单文件残留/损坏与冲突自愈；独立服务端 15 项统计测试覆盖幂等、并发、鉴权、校验、限频、时区和安装事件。服务端完整 195 项测试与 ruff 检查通过、前端构建及 SEO 检查通过；插件完整 767 项测试、类型检查与构建通过。尚未由这些自动测试覆盖 Windows 桌面实测或真实付费生成。本机另做过一次真实路径核对：对已有的 `analytics-id.json` 调用 `analyticsIdentity()`，旧标识原样保留、只补出同值的 `analytics-anchor.json`（老版本升级到本版不会换设备）。
