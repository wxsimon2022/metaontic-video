# 插件消息通知

控制台「插件通知」只填写标题（80字内）和内容（1000字内），可保存草稿、发布、下架或删除。最新发布的消息优先展示，一次显示一条；关闭后显示下一条。编辑或重新上架相同 ID 不重新提醒已关闭用户，新消息须新建。

公开只读 `GET /api/v1/notifications` 返回统一信封及 `data.items`，最多50条已发布消息。无需注册、密钥、设备标识或握手头。控制台 `/api/v1/admin/notifications` 的 GET/POST/PUT/DELETE 均需管理员令牌，编辑与删除用 revision 防并发覆盖。

插件首页与设置页共用消息状态，页面打开时同步、停留每5分钟刷新，5秒超时。断网、HTTP错误、业务错误、损坏响应及响应体挂起均静默保留缓存，不影响创作与设置。不阻断视频任务，不发系统通知或弹窗。只渲染纯文字，无链接或远端 HTML。收到的消息及关闭记录保存在当前 Harness 本机浏览器存储，不向服务端回传已读、关闭状态或消息副本。离线保留本地消息；服务端下架/删除在下次成功同步后移除。清空宿主本地存储会失去关闭记录，可能再次显示；不承诺跨设备同步。

部署服务端后新表自动创建，无配置项或旧表补列；插件需更新才有展示入口。尚未部署、发布或安装本次改动。服务端保存管理端原始消息以供新设备下发，不保存逐设备收件箱。

Windows/macOS 使用相同浏览器 API，无路径、进程或额外依赖；已执行本机构建与模拟回归，尚未进行两平台真实桌面验证。
