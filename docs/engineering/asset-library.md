# 资产库

入口为顶部 conversation.view 标签，绑定当前会话；不在输入框上方增加重复入口。生成结果只投影当前会话已加载记录；工作区上传素材存储于 metaontic-video/assets，以内容摘要去重，侧车元信息保存名称。上传支持图片20MB、视频100MB，每批20项；服务端校验文件头、注册工作区与目录符号链接边界，不允许任意目录写入。

“用于当前对话”只追加引用到草稿，不自动提交或触发付费任务。读取、上传与历史加载具有会话切换隔离；分页每批24项。预览复用宿主本地文件接口和附件缓存，不新增对外文件下载服务。

Windows/macOS共用实现，无新增进程依赖。路径测试覆盖盘符、反斜杠和中文路径；真实Windows桌面操作尚未验证。自动检查包括构建、全量测试和无头Chrome模拟上传、搜索、分页、预览、引用与窄屏交互；模拟浏览器不等于实际宿主桌面验收。安装磁盘摘要与运行模块身份分别检查。
