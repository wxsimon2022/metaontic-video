# 创意视频设计师独立模式

Agent ID为creative-video-designer，宿主预设为同名独立包入口，业务依赖与技能列表均为空。用户提供的Cinematic Video Director V1.0共19节原文保存在src/agents/creative-video-designer/prompt.ts，专属边界提示限定当前会话模型只做设计；四部分输出、15秒/16:9默认值不混入原有制作流程。

公共运行时按宿主当前预设选择该Agent，只注入其专属提示词。视频与专业创作工具由现有注册层业务白名单拒绝，tools/pre-execute也阻止视频生成；允许宿主澄清工具继续使用。预设仅包含身份、提问与上下文压缩，不附加Shell、制作技能或其他执行工具。标准模式和视频创作助手保留原行为。

新增入口、中文/英文元数据及SVG图标；构建清单和产物身份均加入独立预设文件，package exports显式导出，发布包现有通配规则覆盖资源。Windows和macOS共享同一入口，不新增路径或外部进程依赖。

回归验证以真实构建入口确认19节规则、默认值、四部分格式、模式间提示隔离、全部插件业务工具执行拒绝、提问放行和旧模式恢复；预设测试核对两种语言及可执行入口，构建身份防止漏包。未调用付费模型，不能将提示词契约检查当成真实模型输出效果验证。新模式尚未发布，安装验证另记。
