# 宣传视频制作

先读取video-director技能，按其工具和审批流程执行。本技能补充宣传内容要求，不增加制作授权，不替代脚本审核。

## 承接原创意

无论创意是否完整，都先确认“帮我完善 / 保留原方案”，本次已经明确选择时不重复问。完善只补充原卖点的呈现、动作衔接、可拍性和表达，不更换主题、产品、核心情节、人物关系、风格或结尾；必要改动先说明并取得同意。

从需求中提取宣传主体、目标受众、投放场景、希望观众采取的行动、已有卖点和素材。仅缺少影响脚本的关键信息才问，不让用户填写固定长表。

时长、横竖屏、分辨率已写明就直接沿用，不再二次确认；缺失项与完善创意放在同一次ask_user_question中。时长建议15/30/45/60秒及自定义；清晰度480P/720P，未支持的规格说明限制并询问替代，不静默更改。需求与选择均记录在script.md。

## 宣传脚本

按内容组织开场看点、产品或活动价值、真实演示、结尾行动，不强制固定模板或真人口播。生活场景、产品展示、品牌氛围与活动预告按原需求选择；不硬加冲突、反转、人物或对白。

- 卖点必须来自用户或已核实材料，不编造价格、优惠、销量、评价、认证、疗效、功能和效果承诺。缺少的事实先澄清，草稿可明确标“待确认”，不能当成已确认材料提交制作。
- Logo、产品外观、包装、品牌配色与界面以真实素材为准；没有素材就询问或明确使用示意，不假装还原了真实品牌。
- 不承诺模型准确生成商标、字幕或界面文字。用户要求精确文案时先确认呈现方式；未要求字幕不擅自添加。
- 单段上限内的分镜切换在同一次生成完成。独立镜头或付费参考图不自动增加：先说明必要性、调用计划和新增费用，纳入脚本及预算审核。

脚本正文包含：宣传目标、保留的核心创意、已确认规格与风格、主体/素材、时间/景别/画面/完整对白/声音、结尾行动，以及费用预估。展示本版分镜示意图，标明“示意，非实际生成画面”。真实素材与示意图区分清楚。

## 审核与交付

准备完整逐段提示词，正文展示脚本与分镜后调用video_project(action:review)。通过后调用对应视频工具，由其付费审批确认制作，不额外重复问开始制作。

生成每段后先展示视频，再review_segment确认效果，随后进入下一段费用审批。未知或超时任务按原taskId/resume查询；已完成段不重做，新段仍计费。最终成片在前、原始分段在后，正文给出真实可点击链接，交付卡片只登记最终成片。没有实际生成或合并成功时，不声称已经完成。

## 流程画布联动

流程画布是本插件自带的组件，不依赖任何第三方画布插件；左侧栏「MetaOnticVideo流程画布」那一行打开独立页面，视频创作面板里不再内嵌画布。

用户要用MetaOnticVideo制作画布节点时，先用video_canvas(action:list/read)定位项目和节点，读取原稿、分镜、连线端口与参考素材；不让用户手工抄写已有文本，不询问API密钥。遵守原有创意完善、缺失规格、角色图选择和脚本审核流程。video_project.review的specification和随后video_generate/video_extend需携带read返回的canvas对象；图片走video_prepare_image并带canvas。生成、续拍及图片费用审批不能省略；暂停仍须展示真实分段后review_segment。这条联动由用户明确选中画布节点触发，与设置里的自动创建开关无关。

不要用其它画布插件的生成入口代替MetaOnticVideo生成，也不要把它们的画布当成本插件的流程画布。成果只新增成果节点，不覆盖源稿；canvasSync.pending时用video_canvas(action:sync,token)补传，不重新生成、不重复扣费。源稿修改后重新read和review；不复活已删节点。

设置页的「自动创建流程画布」默认关闭。只有开启时普通视频需求才在原有创作流程里自动投影：video_project prepare/review后自动创建流程画布项目、同步完整剧本和实际制作段计划，并提示用户到左侧栏打开；内置画布不能由工具代开，不要声称已打开，也不需要另问是否同步画布。关闭时不要自动建图或同步，也不要对用户说已经建好流程画布，用户明确要用画布就按上面手动read节点、带canvas生成。canvasProject为disabled表示未开启自动投影，unavailable/pending须如实说明，通过video_project status重试同步，不新建创作项目、不重复付费生成。自动建图不代表脚本、费用或分段成果已审核，原审核全部保留。
