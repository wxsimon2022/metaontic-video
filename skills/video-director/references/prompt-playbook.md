# Seedance 提示词手册

## 一、八块公式

每个镜头按下面八块写，顺序固定。不要写成散文，也不要把八块合成一段没有重点的描述。

### 1. 规格

写清画幅、时长、帧率、整体风格，以及不要什么。

```text
9:16 竖屏，15 秒，一镜到底，30fps，真实生活纪录片/手持街采风格，自然光，
无滤镜、无美颜、无特效、无转场、无字幕、无水印、无片头片尾、无 BGM。
```

### 2. 场景

地点 + 时间 + 天气 + 光线方向 + 背景层次 + 地面/道具。

```text
华北平原村庄，秋日下午四点半，村口红砖院墙外。墙根堆着剥好的玉米棒，
地上散落几片玉米皮，旁边停着一辆旧三轮车，远处是土路和杨树，几只鸡在墙根啄食。
暖金色斜阳从画面左侧照进来，砖墙上有斑驳树影，空气里有细小浮尘。
```

### 3. 人物

年龄、脸型、发型、服装、体型、姿态、情绪。主角用**固定锚点**，每个镜头原样复述。

```text
李大爷（画面左）：72 岁，瘦削黝黑，抬头纹很深，花白短寸，穿洗得发白的藏蓝中山装、
灰布裤、沾泥黑布鞋，手背青筋明显；坐在小马扎上，背微驼，脸上带点苦笑和疲惫。
```

### 4. 镜头

机位、景别、焦段、运镜方向与速度、焦点、构图。

```text
手持单机位，轻微呼吸感，全程一镜到底：0-2 秒中景，两人并排靠墙；
2-9 秒缓慢推近左侧李大爷；9-11 秒平稳右摇横移到王大爷；
11-14.5 秒微微推近；14.5-15 秒轻微后拉，两人重新同框。
焦点始终跟着说话人，自然过渡，不做花哨运镜。
```

### 5. 动作与台词

按秒写谁做什么、谁说话、口型、停顿、反应。台词加引号。

```text
0:02-0:04 采访者（画外，语气随意）：“大爷，您家几个儿子啊？”
0:04-0:05 李大爷抬起右手比出三根手指，语气平淡：“仨。”
0:06.5-0:09.5 李大爷扯了下嘴角，苦笑：“享福？仨儿子家轮着住，一个月搬三回。”
说完低头拍掉裤腿上的土，端起搪瓷缸喝了一口。
```

### 6. 声音

同期声、环境声、音色、口音、语速、情绪；是否要 BGM。

```text
同期声，无配乐：鸡叫、远处狗吠和三轮车声、风吹杨树叶、搪瓷缸盖轻响、喝茶声。
两位大爷带一点方言口音，但吐字清楚；语速偏慢，像日常聊天。
```

### 7. 连续性

多镜时，每镜都复述上一镜的人物、服装、场景、光线、道具、声音。

```text
人物、服装、场景、光线与上一镜保持一致：同一面红砖墙、同一辆旧三轮车、
同一时段暖金色斜阳；李大爷仍穿藏蓝中山装，王大爷仍戴旧解放帽。
```

### 8. 限制

只让正在说话的人开口；不串台；手部正常；不出现文字；不换脸。

```text
只有正在说话的人开口，口型与台词逐字同步，其他人物自然闭嘴倾听，不抢话、不串台；
画面保持真实粗粝的生活质感；皮肤纹理、汗渍、衣物褶皱清晰可见；
不出现任何字幕、贴纸、logo 或水印；手部结构正常。
```

## 二、15 秒单镜完整范例

```text
9:16 竖屏，15 秒，一镜到底单条直出，480P，30fps，真实农村生活纪实风格，
自然光拍摄，无滤镜、无美颜、无特效、无转场、无剪辑、无字幕、无背景音乐。

【场景】华北平原村庄，秋日下午四点半，村口一段红砖院墙外。墙根堆着剥好的玉米棒，
地上散落几片玉米皮，旁边停着一辆旧三轮车，远处是土路和杨树，几只鸡在墙根啄食。
暖金色斜阳从画面左侧照进来，砖墙上有斑驳树影，空气里有细小浮尘。

【人物】采访者阿泽：24 岁男生，短寸头，浅灰色连帽卫衣、牛仔裤、运动鞋，
横握手机拍摄，身体微蹲，表情随和。李大爷（画面左）：72 岁，瘦削黝黑，抬头纹很深，
花白短寸，穿洗得发白的藏蓝中山装、灰布裤、沾泥黑布鞋，手背青筋明显；
坐在小马扎上，背微驼，脸上带点苦笑和疲惫。王大爷（画面右）：68 岁，圆脸微胖，
面色红润，戴一顶旧解放帽，深红毛衣背心套白衬衫，黑裤黑布鞋；同样坐小马扎，
翘着二郎腿，手里捧一只掉漆的搪瓷缸，神态松弛。两人相隔约一米五，都靠墙坐着。

【镜头】手持单机位，轻微呼吸感，全程一镜到底：0-2 秒中景，两人并排靠墙，
采访者从右侧入画蹲下举起手机；2-9 秒缓慢推近左侧李大爷，采访者肩膀和手机在前景虚化；
9-11 秒平稳右摇横移到王大爷；11-14.5 秒微微推近王大爷；14.5-15 秒轻微后拉，
两人重新同框。焦点始终跟着说话人，自然过渡，不做花哨运镜。

【对白与动作】
0:02-0:04 采访者（画外，语气随意）：“大爷，您家几个儿子啊？”
0:04-0:05 李大爷抬起右手比出三根手指，语气平淡：“仨。”
0:05-0:06.5 采访者（画外）：“那您挺享福啊。”
0:06.5-0:09.5 李大爷扯了下嘴角，苦笑：“享福？仨儿子家轮着住，一个月搬三回。”
说完低头拍掉裤腿上的土，端起搪瓷缸喝了一口。
0:09.5-0:11 镜头摇到王大爷，采访者（画外）：“大爷，您呢？”
0:11-0:13 王大爷往后一靠，翘着的脚轻轻晃了晃，笑眯起眼：“我呀，五保户，一个人，清闲。”
0:13-0:14.5 他揭开缸盖吹了吹茶叶，抿一口：“每月还有补助，够花。”
0:14.5-0:15 王大爷满足地咂了下嘴；镜头后拉，李大爷转头盯着他，张了张嘴没说出话，表情僵住。

【声音】同期声，无配乐：鸡叫、远处狗吠和三轮车声、风吹杨树叶、搪瓷缸盖轻响、喝茶声。

【要求】只有正在说话的人开口，口型与台词逐字同步，其他人物自然闭嘴倾听，不抢话、不串台；
两位大爷可以带一点方言口音，但吐字清楚；画面保持真实粗粝的生活质感，
皮肤纹理、汗渍、衣物褶皱清晰可见。
```

## 三、5 秒商品口播范例

```text
9:16 竖屏，5 秒，单镜头，商品广告质感但不过度精修，真实自然光。

【场景】米白色梳妆台前，早晨侧逆光，背景虚化的绿植和玻璃杯，台面干净，
只放一支产品和一块粉扑。

【人物】28 岁亚洲女性，鹅蛋脸，低马尾，裸妆，穿米白色针织开衫；
坐姿自然，肩膀放松，直视镜头，语气像跟朋友聊天。

【镜头】固定机位，中近景，50mm 等效焦段，轻微呼吸感；焦点在人物眼睛，
产品在前景清晰可见；构图人物略偏右，产品在左下三分之一。

【动作与台词】
0-1.5 秒 她拿起粉饼盒，拇指推开盒盖，镜头轻微推近产品：
“早上赶时间，底妆我只做这一步。”
1.5-3.5 秒 她用手指蘸粉，在手背推开，抬眼看镜头：
“粉质很细，上脸是哑光，不卡粉。”
3.5-5 秒 她把粉扑按在脸颊，轻轻拍两下，笑一下：
“油皮姐妹，真的可以试试。”

【声音】同期声，轻微环境底噪；女声音色清亮，语速中等，像日常分享，不要播音腔；
无 BGM（后期可加轻快音乐）。

【要求】产品外观、颜色、logo 位置全程一致；只有人物开口，口型与台词同步；
手部动作自然，不遮挡产品正面；不出现任何字幕、价格牌、二维码或水印。
```

## 四、多镜连续性写法

1. **人物锚点复述**：每个镜头都写同一段人物描述，不要写“同上”。
2. **场景锚点复述**：同一面墙、同一张桌子、同一时间段的光线。
3. **动作接续**：上一镜结尾的手部位置、身体朝向、视线方向，下一镜开头接上。
4. **声音接续**：环境声不断；台词说完再切，不要在半句上切。
5. **切镜动机**：换景别、换说话人、换信息点才切；不要为了花哨而切。
6. **首尾帧**：需要精确衔接时，用 `video_generate` 的首帧/尾帧参数，或先保存上一镜最后一帧。

## 五、台词节奏

| 成片时长 | 台词字数（中文） | 建议镜头数 |
| --- | --- | --- |
| 5 秒 | 10–20 字 | 1 |
| 10 秒 | 20–35 字 | 1 |
| 15 秒 | 25–45 字 | 1–2 |
| 30 秒 | 50–90 字 | 2–3 |
| 60 秒 | 100–180 字 | 4–6 |

超过字数就删信息，不要加速；语速过快会导致口型对不上。

## 六、钩子与结构

- **反常识**：先给结论，再解释。“仨儿子的，居然输给了五保户。”
- **利益点**：前 3 秒说清“这条视频能帮你解决什么”。
- **强画面**：先给一个异常动作/表情，再交代背景。
- **结尾**：反转、金句、定格反应、行动指令，四选一，不要都塞。

## 七、常见失败与改写

| 问题 | 改写方向 |
| --- | --- |
| 人物换脸 | 把人物锚点写得更具体，并在每镜复述；减少镜头数；用同一参考图/首帧 |
| 手部畸形 | 减少手部特写；写“双手自然放在膝盖上”“手指放松”；避免拿细小物件 |
| 口型对不上 | 缩短台词；把台词按秒标点；写“只有说话的人开口” |
| 画面出现文字 | 在规格和限制里都写“无字幕、无文字、无水印、无 logo” |
| 审核拒绝 | 去掉真人/名人/血腥/政治/未成年风险；改虚构人物、中性场景 |
| 风格太“AI” | 加“手机随手拍、自然光、轻微手持晃动、皮肤纹理清晰、无磨皮” |
| 时长超限 | 改成 14 秒；或拆成两个镜头分别生成再合并 |
| 声音不连续 | 每镜都写环境声和音色；用同一段环境声铺底；台词不要在半句切 |
