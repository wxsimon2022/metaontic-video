# Seedance 提示词手册

## 一、结构化执行提示词

按下面八块组织信息，简单场景可以合并。优先保留主体、动作、镜头和对白，避免重复堆叠限制；以已审核脚本为准。

### 1. 规格

写清画幅、时长、整体风格和必要限制。以下纪实与口播示例仅适用于相应题材，不是全局默认；动画、产品展示、风景等采用已审核脚本选择的风格、声音与镜头，无必要不加对白。当前生成固定 720p；帧率以实际文件探测为准，不把提示词中的帧率当作接口保证。

```text
9:16 竖屏，15 秒，一镜到底，720p，真实生活纪录片/手持街采风格，自然光，
无滤镜、无美颜、无特效、无转场、无字幕、无水印、无片头片尾、无 BGM。
```

### 2. 场景

地点 + 时间 + 天气 + 光线方向 + 背景层次 + 地面/道具。

```text
华北平原村庄，秋日下午四点半，村口红砖院墙外。墙根堆着剥好的玉米棒，
地上散落几片玉米皮，旁边停着一辆旧三轮车，远处是土路和杨树，几只鸡在墙根啄食。
暖金色斜阳从画面左侧照进来，砖墙上有斑驳树影，空气里有细小浮尘。
```

### 3. 人物

年龄、脸型、发型、服装、体型、姿态、情绪。主角用**固定标签**和2–3个稳定特征，续拍只补充状态变化，不反复堆叠人物细节。

```text
李大爷（画面左）：72 岁，瘦削黝黑，抬头纹很深，花白短寸，穿洗得发白的藏蓝中山装、
灰布裤、沾泥黑布鞋，手背青筋明显；坐在小马扎上，背微驼，脸上带点苦笑和疲惫。
```

### 4. 镜头

机位、景别、焦段、运镜方向与速度、焦点、构图。

```text
手持单机位，轻微呼吸感，全程一镜到底：0-2 秒中景，两人并排靠墙；
2-9 秒缓慢推近左侧李大爷；9-11 秒平稳右摇横移到王大爷；
11-14.5 秒微微推近；14.5-15 秒轻微后拉，两人重新同框。
焦点始终跟着说话人，自然过渡，不做花哨运镜。
```

### 5. 动作与台词

按秒写谁做什么、谁说话、口型、停顿、反应。台词标明说话者与语言，可用 {台词}；音效用 <音效>，音乐用（音乐）。

```text
0:02-0:04 采访者（画外，语气随意）：“大爷，您家几个儿子啊？”
0:04-0:05 李大爷抬起右手比出三根手指，语气平淡：“仨。”
0:06.5-0:09.5 李大爷扯了下嘴角，苦笑：“享福？仨儿子家轮着住，一个月搬三回。”
说完低头拍掉裤腿上的土，端起搪瓷缸喝了一口。
```

### 6. 声音

同期声、环境声、音色、口音、语速、情绪；是否要 BGM。

```text
同期声，无配乐：鸡叫、远处狗吠和三轮车声、风吹杨树叶、搪瓷缸盖轻响、喝茶声。
两位大爷带一点方言口音，但吐字清楚；语速偏慢，像日常聊天。
```

### 7. 连续性

多镜时保持主体标签稳定；只补充必要的空间、动作与声音交接，删除无变化的重复说明。

```text
人物、服装、场景、光线与上一镜保持一致：同一面红砖墙、同一辆旧三轮车、
同一时段暖金色斜阳；李大爷仍穿藏蓝中山装，王大爷仍戴旧解放帽。
```

### 8. 限制

只让正在说话的人开口；不串台；手部正常；不出现文字；不换脸。

```text
只有正在说话的人开口，口型与台词逐字同步，其他人物自然闭嘴倾听，不抢话、不串台；
画面保持真实粗粝的生活质感；皮肤纹理、汗渍、衣物褶皱清晰可见；
不出现任何字幕、贴纸、logo 或水印；手部结构正常。
```

## 二、15 秒单镜完整范例

```text
【规格】9:16 竖屏，15 秒，720p，一镜到底，真实生活纪实风格，自然光，无字幕、无水印、无 BGM。
【场景】秋日下午，村口红砖墙边，暖色侧光；两张马扎，背景有旧三轮车。
【人物】李大爷在左，72 岁，瘦削，花白短发，藏蓝外套，灰布裤；
王大爷在右，68 岁，圆脸，灰短发，深红毛衣，黑裤，手捧搪瓷缸。
【镜头】单机位中景，两人始终同框；说话时缓慢推近，保留另一人的反应，不切镜。
【动作与台词】
0–2 秒：两人坐着喝茶，李大爷轻叹。
2–6 秒：李大爷看向王大爷：“三个儿子，一个月搬三回家。”
6–8 秒：王大爷放下茶缸，李大爷等他回应。
8–11 秒：王大爷微笑：“我一个人，倒省心。”
11–15 秒：李大爷愣住，低头笑了一下；王大爷继续喝茶。留白结束，不新增台词。
【声音】两位老人普通话带轻微地方口音，语速平缓；背景只有轻风和远处鸟鸣。
【连续性与限制】人物外貌、服装、左右位置稳定；仅说话者开口，另一人自然倾听；不新增人物或文字。
```

## 三、5 秒商品展示口播范例

```text
【规格】9:16 竖屏，5 秒，720p，单镜头，自然晨光，无字幕、无水印、无 BGM。
【场景】米白色梳妆台，背景虚化，台面只放一盒粉饼。
【人物】28 岁女性，低马尾，米白针织衫，自然妆容。
【镜头】固定中近景，人物与产品在同一焦平面，不切镜。
【动作与台词】0–1 秒：她举起已打开的粉饼盒；1–4 秒：看镜头说
“赶时间，底妆就用这一盒。”；4–5 秒：保持产品正面朝向镜头，微笑停留。
【声音】清晰自然的同期声，语速适中，轻微室内环境声。
【连续性与限制】包装外观和已有标识保持一致，不新增标识或文字；手指不遮挡产品正面。
```

## 四、多镜连续性写法

1. **人物形象复述**：用2–3个稳定特征定义主体标签，各段始终使用同一标签。
2. **场景复述**：同一面墙、同一张桌子、同一时间段的光线。
3. **动作接续**：上一镜结尾的手部位置、身体朝向、视线方向，下一镜开头接上。
4. **声音接续**：环境声不断；台词说完再切，不要在半句上切。
5. **切镜动机**：换景别、换说话人、换信息点才切；不要为了花哨而切。
6. **首尾帧**：需要精确衔接时，用 `video_generate` 的首帧/尾帧参数，或先保存上一镜最后一帧。

## 五、台词节奏

| 成片时长 | 台词字数（中文） | 建议镜头数 |
| --- | --- | --- |
| 5 秒 | 10–20 字 | 1 |
| 10 秒 | 20–35 字 | 1 |
| 15 秒 | 有对白时约25–45字，无对白不填充台词 | 按故事选择1镜或少量切镜，一次生成 |
| 30 秒 | 50–90 字 | 2–3 |
| 60 秒 | 100–180 字 | 4–6 |

超过字数就删信息，不要加速；语速过快会导致口型对不上。

## 六、钩子与结构

- **反常识**：先给结论，再解释。“仨儿子的，居然输给了五保户。”
- **利益点**：前 3 秒说清“这条视频能帮你解决什么”。
- **强画面**：先给一个异常动作/表情，再交代背景。
- **结尾**：反转、金句、定格反应、行动指令，四选一，不要都塞。

## 七、常见失败与改写

| 问题 | 改写方向 |
| --- | --- |
| 人物换脸 | 把人物形象写得更具体，并在每镜复述；减少镜头数；用同一参考图/首帧 |
| 手部畸形 | 减少手部特写；写“双手自然放在膝盖上”“手指放松”；避免拿细小物件 |
| 口型对不上 | 缩短台词；把台词按秒标点；写“只有说话的人开口” |
| 画面出现文字 | 在规格和限制里都写“无字幕、无文字、无水印、无 logo” |
| 审核拒绝 | 去掉真人/名人/血腥/政治/未成年风险；改虚构人物、中性场景 |
| 风格太“AI” | 加“手机随手拍、自然光、轻微手持晃动、皮肤纹理清晰、无磨皮” |
| 时长超限 | 先确认请求时长与实际媒体时长；需缩短时先征得用户同意。≤15 秒仍保持一次生成 |
| 声音不连续 | 每镜都写环境声和音色；用同一段环境声铺底；台词不要在半句切 |


## 八、续拍与重复片段处理

- 全片脚本使用全局时间；每段单独写执行范围，同时标出“已完成状态 → 下一动作 → 本段结束状态”。
- 列出此前已说的台词（仅作排除上下文）和本段新台词，禁止把全片对白在每段重演。没有分时脚本时，先补齐时间安排。
- 接缝放在完整句结束、自然停顿或动作完成处。不要把一个词、递接物品的瞬间拆到两段。
- 参考视频结尾用于匹配状态，不复制为续拍开头；只输出新增内容，不回放、不倒回动作。
- 先展示每段再继续。检查接缝前后 2 秒，区分画面原样重叠与模型重新表演；静态构图相似不等于重复。
- 确认重复的起止位置后，使用 seamTrimSeconds 逐接缝指定裁剪量（例如 0.5,0）。留空时 2.0 默认裁前段尾6帧和后段头1帧，2.5 不裁；填 0 关闭默认裁剪。手动值覆盖模型策略，不要额外固定裁所有接缝，也不要仅凭时长推断重复。
- 裁剪必须音视频同步，切在完整台词之外；若重复段混有新对白，先给裁剪预览，必要时经用户确认重新续拍。
- 保留原始分段，裁剪输出为新文件；交付报告实际时长，不补静帧或慢放凑整数时长。


### 官方 2.0 接缝处理

依据 https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=zh 的“视频衔接”建议，
2.0 默认每个接缝裁掉前段尾部 6 帧、后段头部 1 帧，按各段实际帧率换算；裁后直接拼接，不再叠加交叉淡化。
这用于缓解接缝回退，不保证消除模型重演的整句对白。2.5 不默认套用此规则。
seamTrimSeconds 留空使用上述默认值，填 0 关闭，填其他值覆盖为逐接缝头部裁剪。
所有分段始终保留，裁剪只作用于副本；交付实际时长及裁剪记录。


## 九、火山进阶规则（按模型区别使用）

来源：
- https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=zh
- https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh

先定义主体、再组织事件，避免把完整剧本和重复限制堆进提示词。人物使用2–3个稳定特征定义唯一标签；道具与素材的对应关系写清，不用含混的“他/另一个人”。只引用实际传入的素材，素材编号按请求顺序核对。

2.0：按事件顺序写“机位/运镜 → 主体动作与表情 → 空间变化 → 声音”。时间点只作节奏参考，不承诺逐秒服从。动作说明部位、幅度、速度及承接；情绪转成可见表情和身体变化。
2.5：允许本段局部0秒起连续时间区间，不留无意的空档，不用秒点控制动作频次；复杂动作概括，只细化关键动作。参考素材已明确的动作与运镜不重复展开成矛盾细节。

提交的每段提示词只包含本段内容。全局剧本时间用于制作规划，本段时间用于模型；不能把整片15–20秒直接写成一个5秒请求的局部时间。
对白格式明确说话者、语言、语气和原句；2.0可用 {台词}、<音效>、（音乐）区分声音。没有对白或配乐明确注明。

20秒双人对话的 segmentPrompts 示例（2.0，15+5）：
1. “左侧浅色衬衫女子为小林，右侧蓝外套男子为老周。公园长椅，暖色侧光，固定中景，同框。小林举起手机问{这笔钱去哪了？}；老周低头看屏幕，轻声答{先存起来了。} 小林收回手机，老周双手放回膝上。中文同期声，微风，无配乐、字幕。”
2. “向后延长视频1。老周双手已放在膝上；小林保持手机在手中，抬眼看老周。小林笑着说{这回算你靠谱。} 老周松口气微笑，二人安静停留。保持同框中景与原光线、音色，仅输出这段新对白和反应，不再展示或递接手机。无配乐、字幕。”

多镜切换按已审核脚本采用，不额外增加付费调用；用户要求一镜到底时不切镜。单镜也可用“先/随后/最后”分阶段描述，不把阶段误写为切镜。


### 提交前必须满足

多段生成必须提供与计划等长的 segmentPrompts，插件在提交付费任务前校验；缺失不会自动粘贴全片剧本兜底。
脚本供审核的全片时间表保留；2.0模型指令改为镜头序号或连续动作阶段，2.5才使用局部整数秒区间。
简洁地定义主体、描述本段目标事件、给出动作承接与镜头安排，最后补必要的音频和字幕限制。优先正向描述画面，不堆叠“不要”。
只按插件实际支持并已传入的素材编号引用，不要求未传入的音色音频、第二张参考图或视频。平台能力与插件当前支持范围分开说明。
